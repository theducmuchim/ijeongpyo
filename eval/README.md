# AI 평가하는 법

'길을 잃었어요'에서 AI가 얼마나 잘 맞히는지 숫자로 재는 도구입니다. 지시문(`lib/prompts.ts`)을 고칠 때마다 같은 사진으로 다시 재서, 고친 게 나아졌는지 나빠졌는지 확인합니다.

제일 중요하게 볼 숫자는 **확신했는데 틀림**입니다. AI가 "확실하다"고 해 놓고 틀리면 사용자는 그 말을 믿고 엉뚱한 방향으로 걷게 됩니다. AI가 "모르겠어요, 한 장 더 찍어 주세요"라고 하는 건 귀찮을 뿐 위험하지는 않습니다. 그래서 맞힌 비율이 조금 낮아지더라도 확신했는데 틀린 비율이 줄어드는 쪽이 낫습니다.

## 1. 준비물

1. **경로 파일.** 앱에서 길을 등록하고 저장한 뒤, 설정 → 시험 기간 → "평가용 경로 내보내기"를 누릅니다. 받은 `.json` 파일을 `eval/routes/`에 넣습니다. 이름은 `등굣길.json`처럼 알아보기 쉽게 바꿔도 됩니다.
2. **평가 사진 30장.** 등록한 길을 다시 걸으며 찍습니다. 앱에서 찍지 말고 휴대폰 기본 카메라로 찍어서 `eval/photos/`에 넣습니다. 크기는 도구가 앱과 똑같이 줄여서 보냅니다.
   - 갈림길 근처 사진 20장 정도: 카드마다 2장씩, 정면과 조금 비튼 각도
   - 엉뚱한 곳 사진 10장 정도: 경로에서 한 블록 벗어난 골목, 비슷하게 생긴 다른 편의점 앞 같은 곳. AI가 헷갈릴 만한 곳일수록 좋습니다.
   - 얼굴, 차 번호판, 문패가 나오지 않게 찍어 주세요. 이 사진들은 구글 AI로 보내집니다.
3. **정답표.** `eval/answers.csv`를 엑셀이나 구글 시트로 열어 한 줄에 사진 한 건씩 적습니다.

| 칸 | 적는 것 | 예 |
|---|---|---|
| 사진 | `eval/photos` 안의 파일 이름. 두세 장을 같이 보내려면 `+`로 잇기 | `a01.jpg` 또는 `a05.jpg+a06.jpg` |
| 경로 | `eval/routes` 안의 파일 이름 | `등굣길.json` |
| 마지막카드 | 그 사진을 찍기 직전에 지나간 카드 번호. 앱이 AI에게 알려 주는 값 | `3` |
| 정답카드 | 그 사진이 몇 번 카드 근처인지. 엉뚱한 곳이면 `없음` | `4` / `없음` |
| 메모 | 아무거나 (비워도 됨) | `밤에 찍음` |

예:

```
사진,경로,마지막카드,정답카드,메모
a01.jpg,등굣길.json,1,2,
a02.jpg,등굣길.json,1,2,비스듬히
b01.jpg,등굣길.json,3,없음,옆 골목 편의점
```

"마지막카드"를 일부러 틀리게 적어 보는 것도 좋은 시험입니다. 실제로 길을 잃은 사람은 카드를 넘기지 않고 지나쳤을 수 있으니까요.

## 2. 돌리기

`.env.local`에 `GEMINI_API_KEY`가 있어야 합니다. 시험 모드(키 없음)로는 돌아가지 않습니다.

```bash
npm run eval              # 정답표 전체
npm run eval -- --limit 3 # 앞의 3건만 (지시문을 고친 뒤 빨리 확인할 때)
```

무료 등급은 1분에 부를 수 있는 횟수가 정해져 있어서, 한 건마다 6.5초씩 쉽니다. 30건이면 4분쯤 걸립니다. 한도에 걸리면 1분 쉬고 다시 합니다. 쉬는 시간은 `EVAL_DELAY_MS=10000 npm run eval`처럼 바꿀 수 있습니다.

평가도 무료 한도를 씁니다. 30건을 돌리면 30번 이상 부르니, 앱으로 실제 걷기 시험을 하는 날에는 평가를 미뤄 두세요.

## 3. 결과 보기

화면에 한 건씩 `[O]` 맞음, `[X]` 확신했는데 틀림, `[?]` 모르겠다고 함, `[!]` 오류로 찍히고, 마지막에 요약이 나옵니다.

- `eval/results/날짜-지시문번호.csv`: 건별로 AI가 뭘 봤고 뭐라고 답했는지. `[X]`인 줄의 "AI가 본 것"과 "이유"를 읽으면 지시문을 어떻게 고칠지 보입니다.
- `eval/results/history.csv`: 잴 때마다 한 줄씩 쌓입니다. "지시문" 칸은 지시문 글자로 만든 번호라서, 지시문을 한 글자라도 고치면 번호가 바뀝니다. 어느 지시문이 제일 나았는지 이 파일로 비교합니다.

## 4. 사진과 경로 파일은 깃허브에 올리지 않습니다

`eval/photos/`와 `eval/routes/`는 `.gitignore`에 넣어 두었습니다. 사는 동네와 다니는 길이 그대로 드러나기 때문입니다. 결과 파일에도 AI가 쓴 장소 설명이 들어가니, 공개 저장소라면 올리기 전에 한번 읽어 보세요.
